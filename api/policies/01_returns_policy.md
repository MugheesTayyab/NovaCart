# Returns Policy

## 1. Who this policy covers

**1.1** This policy covers items marked "Sold by NovaCart". Items sold by marketplace sellers follow the same windows and have extra rules in [file 18, Section 1].

**1.2** To return an item, the customer opens My Orders, selects "Return item" and submits the request inside the return window in Section 2. NovaCart approves or declines the request within 1 business day.

**1.3** An approved return must be handed to the courier within 5 days of approval. If it is not, the approval lapses and a new request is needed. The return window still applies to the new request.

**1.4** NovaCart error means one of the following: the wrong item was delivered, the item is defective, or the item was damaged in transit, reported within the limits in [file 07, Section 1]. Every other return is a change-of-mind return.

## 2. Return windows

**2.1** Return windows count from the delivery date (see [file 00, Section 1]).

| Category | Return window |
| --- | --- |
| Electronics | 7 days |
| Clothing | 30 days |
| Furniture/bulky | 14 days |
| Personal care | 14 days, sealed items only |
| Grocery/perishables | Not returnable for change of mind (see [file 04, Section 1]) |

**2.2** Remote areas and International orders have their own return windows (see [file 19, Section 4] and [file 20, Section 6]).

**2.3** When the window has passed, change-of-mind returns are not accepted. A defective electronics or furniture item can still be handled under warranty (see [file 08, Section 4]).

**2.4** Items that cannot be returned for change of mind are listed in [file 04, Section 1].

## 3. Condition of returned items

**3.1** Electronics must come back in the original packaging with all accessories. If an electronics item has been opened and is not defective, a restocking fee of 15% of the paid price applies. A sealed electronics item has no restocking fee.

**3.2** Clothing must be unworn and unwashed with the tags attached. There is no restocking fee for clothing.

**3.3** Furniture/bulky items must be unused and in the original packaging. A restocking fee of 10% of the paid price applies to non-defective furniture/bulky items.

**3.4** Personal care items must be sealed and unopened. There is no restocking fee for personal care.

**3.5** No restocking fee is charged on a NovaCart error return.

## 4. Return fees

**4.1** One return fee is charged per return request, not per item. If the request includes any furniture/bulky item, the fee is the pickup fee of Rs. 2,000. Otherwise the fee is the return label fee of Rs. 200.

**4.2** No return fee is charged on a NovaCart error return.

**4.3** Remote areas pay a return label fee of Rs. 400 (see [file 19, Section 4]). International customers arrange and pay their own return shipping (see [file 20, Section 6]).

## 5. How the refund amount is worked out

**5.1** The paid price of an item is its selling price minus its share of any code discount (see [file 12, Section 6]), or its share of the bundle price if it was bought in a bundle (see [file 13, Section 4]).

**5.2** The refund for each returned item is its paid price minus any restocking fee. The restocking fee is a percentage of the paid price, rounded half up.

**5.3** The refund total for a return request is the sum of the item refunds minus the one return fee from Section 4. The refund total is never below Rs. 0.

**5.4** Shipping fees and other fees paid at checkout are handled in [file 03, Section 2]. Refund method and timing are in [file 03, Section 3].

## 6. Other return rules

**6.1** NovaCart does not offer direct exchanges. The customer returns the item and places a new order.

**6.2** Returned items are inspected within 2 business days of NovaCart receiving them. The refund approval date is the day the inspection is completed.

**6.3** A return request can cover some or all of the items in an order.
