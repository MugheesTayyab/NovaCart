# Returns Policy (Version 2)

## 1. Who this policy covers

**1.1** This policy covers items marked "Sold by NovaCart".

**1.2** To return an item, the customer opens My Orders, selects "Return item" and submits the request inside the return window in Section 2. NovaCart approves or declines the request within 1 business day.

**1.3** An approved return must be handed to the courier within 5 days of approval. If it is not, the approval lapses and a new request is needed.

**1.4** NovaCart error means one of the following: the wrong item was delivered, the item is defective, or the item was damaged in transit. Every other return is a change-of-mind return.

## 2. Return windows

**2.1** Return windows count from the delivery date.

| Category | Return window |
| --- | --- |
| Electronics | 10 days |
| Clothing | 14 days |
| Furniture/bulky | 14 days |
| Personal care | 14 days, sealed items only |
| Grocery/perishables | Not returnable for change of mind |

**2.2** When the window has passed, change-of-mind returns are not accepted.

## 3. Condition of returned items

**3.1** Electronics must come back in the original packaging with all accessories. If an electronics item has been opened and is not defective, a restocking fee of 10% of the paid price applies. A sealed electronics item has no restocking fee.

**3.2** Clothing must be unworn and unwashed with the tags attached. There is no restocking fee for clothing.

**3.3** Furniture/bulky items must be unused and in the original packaging. A restocking fee of 10% of the paid price applies to non-defective furniture/bulky items.

**3.4** Personal care items must be sealed and unopened. There is no restocking fee for personal care.

**3.5** No restocking fee is charged on a NovaCart error return.

## 4. Return fees

**4.1** One return fee is charged per return request, not per item. If the request includes any furniture/bulky item, the fee is the pickup fee of Rs. 1,500. Otherwise the fee is the return label fee of Rs. 150.

**4.2** No return fee is charged on a NovaCart error return.

## 5. How the refund amount is worked out

**5.1** The paid price of an item is the amount the customer paid for it after any discount.

**5.2** The refund for each returned item is its paid price minus any restocking fee, rounded half up.

**5.3** The refund total for a return request is the sum of the item refunds minus the one return fee. The refund total is never below Rs. 0.

**5.4** Refunds go back to the original payment method.
