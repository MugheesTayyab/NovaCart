# Data Requests and Retention

## 1. Asking for a copy of your data

**1.1** A customer can ask for a copy of their personal data. NovaCart answers within 30 calendar days.

**1.2** The first request in any 12-month period is free. Each further request in the same period costs Rs. 500.

**1.3** NovaCart verifies the customer's identity before sharing data.

## 2. Deleting data

**2.1** A customer can ask for their account and personal data to be deleted. NovaCart completes the deletion within 30 calendar days.

**2.2** NovaCart cannot delete data for an order that is still inside its return window or warranty period, or data it must keep by law, until that period ends.

## 3. How long data is kept

**3.1** Retention periods are listed below.

| Data | Retention |
| --- | --- |
| Order and invoice records | 6 years |
| Account data | Deleted or anonymised 12 months after the last activity |
| Customer support chat records | 24 months |
| Full card numbers | Never stored by NovaCart |

## 4. Corrections

**4.1** NovaCart corrects wrong personal data within 7 days of a request.

## 5. Marketing preferences

**5.1** An unsubscribe request takes effect within 3 business days.
